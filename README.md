# Real-Time Chat Application (Go + React + NATS)

Это полнофункциональное чат-приложение, созданное для демонстрации современной бэкенд-архитектуры с использованием Go, обмена сообщениями через NATS и контейнеризации с помощью Docker. Фронтенд построен на React.

## Технологический стек

*   **Бэкенд:** Go
    *   `gorilla/websocket` для WebSocket-соединений.
    *   `nats-io/nats.go` для взаимодействия с NATS.
*   **Фронтенд:** React
*   **Система обмена сообщениями:** NATS Server
*   **Контейнеризация:** Docker & Docker Compose

## Архитектура

Проект полностью контейнеризирован и состоит из трех основных сервисов, управляемых через `docker-compose`:
1.  `frontend`: React-приложение, собранное для продакшена и раздаваемое через легковесный веб-сервер Nginx.
2.  `backend`: Go-приложение, которое обрабатывает WebSocket-соединения от клиентов.
3.  `nats`: NATS-сервер, который выступает в роли брокера сообщений.

**Логика работы сообщения:**
1.  Клиент (React) отправляет JSON-сообщение через WebSocket на `backend`.
2.  `backend` получает сообщение и немедленно **публикует** его в "тему" на сервере `nats`.
3.  `backend` также **подписан** на эту "тему". `nats` мгновенно доставляет это сообщение всем подписчикам (включая сам `backend`).
4.  Получив сообщение от `nats`, `backend` рассылает его всем подключенным WebSocket-клиентам.

Такая архитектура делает систему горизонтально масштабируемой. Мы можем запустить несколько экземпляров `backend`, и все они будут обмениваться сообщениями через единый NATS, обеспечивая работу чата для всех пользователей.

## Быстрый старт

### Требования
*   [Docker](https://www.docker.com/get-started)
*   [Docker Compose](https://docs.docker.com/compose/install/) (обычно устанавливается вместе с Docker Desktop)

### Запуск приложения
1.  Клонируйте репозиторий:
    ```bash
    git clone <your-repo-url>
    ```

2.  Перейдите в корневую папку проекта:
    ```bash
    cd Chat
    ```

3.  Запустите все сервисы с помощью Docker Compose:
    ```bash
    docker-compose up --build
    ```
    *   Флаг `--build` необходим при первом запуске или после внесения изменений в код, чтобы пересобрать образы контейнеров.

4.  Откройте браузер и перейдите по адресу **[http://localhost:3000](http://localhost:3000)**.

Приложение готово к работе! Вы можете открыть несколько вкладок для имитации общения нескольких пользователей.

### Остановка приложения
1.  Чтобы остановить все контейнеры, вернитесь в терминал, где был запущен `docker-compose`, и нажмите `Ctrl + C`.
2.  Для удаления контейнеров и созданной сети (рекомендуется после остановки) выполните команду:
    ```bash
    docker-compose down
    ```
